# 剪贴板拼图

打开「剪贴板拼图」后，直接粘贴文字、图片或链接，或开启「开始收集」监听后续复制。一个页面对应一个任务；开启同类新页面会创建新的任务。收集浮窗优先打开当前收集任务，没有正在收集的任务时打开最近任务。多个视图打开同一个任务时会同步；在浮窗中新建任务即可独立编辑。

独立窗口默认 **680 × 480**，可置顶、拖动、缩放和关闭。主程序不需要保持打开。收集关闭时不运行剪贴板监听；收集开启后，关闭全部界面仍会收集到指定任务。重新启动应用时默认暂停收集。

## 画布操作

- 默认鼠标工具：拖动对象移动，左键在空白处拖动框选；Ctrl 点击增减选择。一次复制的混合内容默认组合在一起，可右键取消组合。
- 将单个对象或框选的一组内容拖到其他窗口，会复制到松开鼠标的位置，并保留相对布局；原件和副本分别编辑。
- 剪刀工具：框出任意区域，包括图片内部区域，生成图片副本。原件保留。
- 底部工具栏：选择、剪刀、文字、图片、矩形、箭头、画笔；更多菜单可插入链接和便签。
- 空格拖动画布；滚轮平移；Ctrl + 滚轮缩放。拖动对象靠近拼图框或其他对象时吸附到边缘或中心，Alt 临时关闭吸附。
- 「对象属性」可以修改尺寸、名称、文字字号和形状颜色；支持对齐、组合、竖向和网格排列。
- Ctrl + Z 撤销，Ctrl + Y 重做，Ctrl + S 保存，Ctrl + D 创建副本，Delete 删除，Esc 返回选择。

## 收集与输出

自动收集只针对明确指定的一个任务；切换页面和窗口不会改变收集目标。内容自动排到收集区的空闲列。一份剪贴板内的文字、图片与链接作为一个组合保留。主动重复复制会保留重复片段。

支持 Windows 文字、PNG、DIB/DIBV5 位图和 HTML 中的图片、链接。网页图片在后台取得并转存为本地 PNG，不执行网页脚本。需要登录、防盗链、超时或超出读取限额的图片会保留提示和来源入口；可以单独复制该图片再次粘贴。GIF 保留首帧。带剪贴板排除标记的内容不收集，工具自身输出带标记以避免循环。

导出可选拼图框、全部或所选内容，支持 1×/2×、透明背景、保存 PNG 或复制图片。辅助线和画布点阵不参与导出。PNG 不保留可点击链接；可编辑文字和链接留在拼图任务中，也可分别复制文字或链接。成功复制拼图图片后，当前任务的自动收集会暂停。

## 保留与资源

临时任务默认按最后修改时间保留 24 小时，可改为 7 天或手动清理。手动保存的拼图长期保留。正在打开或收集的任务不会自动过期。数据保存在 DtKit 管理目录的 `Kits/ClipboardPuzzles`，导出图片保存在 `Downloads`；移动 DtKit 存储目录会一起迁移。

原图按内容摘要共享存储，跨任务复制不重复保存图片。画布只挂载可见对象，图片使用 640 像素缩略图；缩略图缓存限制为 16 张且不超过约 8 MB 数据。导出依次读取原图，过期的导出请求会取消，后台磁盘写入不阻塞窗口。

单任务最多 1000 个对象、12 MB 对象数据；单图最多 32 MB / 4000 万像素；图片库限额 2 GB，后台待处理剪贴板数据限额 64 MB。达到限额会明确暂停或提示，不会覆盖已保存内容。未被任务引用的图片在下次启动存储仓库时清理，以保留当前窗口的撤销资源。不包含 OCR 模型或持续轮询。

## 验证

```powershell
node --test tests/clipboard-puzzle-model.test.js
cargo test --manifest-path src-tauri/Cargo.toml --locked clipboard_puzzle
npm run build
npm run tauri build -- --debug --no-bundle --config tests/native-webview.config.json
python tests/clipboard-puzzle-native-smoke.py
```

原生验证使用独立应用标识和数据目录。跨窗口验证驱动 HTML 拖放事件并检验真实仓库的副本标识和独立编辑，不替代人工的跨窗口鼠标拖放验收。剪贴板测试仅在原内容能够完整备份时运行，并防止覆盖测试期间用户新复制的内容。
