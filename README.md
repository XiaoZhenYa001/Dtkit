## 工具与功能

DtKit 面向 Windows 桌面使用，将常用开发、设计和效率工具集中在一个应用中。工具按需加载，支持多标签和独立窗口；系统功能需要在桌面应用中使用，浏览器预览主要用于界面开发。

### 开发与转换

| 工具 | 作用 |
| --- | --- |
| 时间戳转换 | 在 Unix 时间戳与日期时间之间转换。 |
| JSON / YAML / XML 转换 | 在本地校验、格式化、压缩和转换数据。 |
| Base64 编解码 | 编码和解码文本及二进制数据。 |
| MD5 / Hash | 计算文本或文件的 MD5、SHA-1、SHA-256、SHA-512 摘要。 |
| 二维码生成 | 自定义二维码样式和 Logo，导出多种格式。 |
| URL 编码 | 对网址、组件或表单参数编解码，逐行处理并查看查询参数。 |
| Crontab 解释 | 解释标准五段规则，预估本地时间或 UTC 的后续执行时间；不创建任务。 |
| 单位换算 | 换算数据、长度、质量、温度等九类单位，设置显示精度。 |
| HTML 预览 | 编辑 HTML、CSS、JavaScript，在沙盒中预览并切换设备视口。 |

| 工具 | 作用 |

| 课表 | 按周或日程查看课程，管理周次、冲突、导入导出和桌面小部件。 |

## 🎯 项目特点

**0.2.12**：桌面空间改为独立快捷键呼出的横向玻璃面板，平时隐藏；支持真实打开文件与应用、空格快速预览、固定与拖动排序保存。旧桌面宿主、收纳柜布局与玻璃旋钮实现已移除。原有分类侧栏继续作为并列选项，桌面图标由用户自行控制显示。

**0.2.10**：新增[剪贴板拼图](docs/clipboard-puzzle.md)，支持混合内容收集、无限画布、区域副本、跨窗口复制与 PNG 输出；独立窗口默认横向 680 × 480。主程序采用暖白、墨色与橙色配色，保留原有侧边栏选项和顺序。

- ✅ **模块化设计** - 工具与框架分离，易于添加新工具
- ✅ **ES6 模块化** - 使用现代 JavaScript 模块系统
- ✅ **工具注册机制** - 统一的工具管理和生命周期控制
- ✅ **无缝扩展** - 添加新工具无需修改框架代码
- ✅ **样式保持** - HTML/CSS 结构完全保持不变

## 🚀 快速开始

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run tauri dev
```

仅调试前端时可以运行：
```bash
npm run dev
```

### 构建应用
```bash
npm run tauri build
```

`tauri build` 会自动先执行 `npm run build`，生成经过压缩和分包的 `dist/` 前端产物。

### 更新图标子集

新增或移除 `ri-*` 图标后，安装一次字体构建依赖并重新生成子集：

```bash
python -m pip install fonttools brotli
npm run icons:build
```

`npm run test:js` 会检查应用引用的完整图标类是否全部包含在子集中。

### HTML 预览

编辑区提供 HTML、CSS、JavaScript 标签、行号、光标位置和代码大小，分栏可拖动或用方向键调整。实时预览采用 500ms 防抖；关闭后可用「运行」或 `Ctrl+Enter` 更新，状态栏区分未运行的修改、更新完成和脚本错误。手机与平板模式使用 390×844、768×1024 的真实 CSS 视口，按可用空间缩放显示；自适应模式填满预览区。`Esc` 退出全屏或离开编辑区，`Shift+Tab` 返回语言标签。

工具拆分为模板、示例、编辑工作区和运行生命周期模块。各页面独立保留代码、选区、滚动位置、分栏与预览尺寸；隐藏时卸载沙盒，手动模式恢复上次运行内容并保留草稿。运行 `npm run test:html-preview-ui` 验证双宿主布局、编辑、执行、状态恢复与响应式预览，效果截图位于 `tests/artifacts/html-preview/`。

#### 更新预览运行器

HTML 预览运行器使用 CSP SHA-256 白名单。修改 `src/preview-runner.js` 后需要更新哈希：

```bash
npm run csp:hash
```

`npm run test:js` 会检查生产与开发 CSP 中的哈希是否和运行器源码一致。

## 软件分析

软件清单按需读取 Windows 卸载登记，支持名称、版本、发布者、路径搜索，以及范围、发布者、可分析位置和扫描状态组合筛选。登记日期与大小由安装程序提供；缺失大小保持未知，不计为零。CSV 导出全部筛选结果，包含分页之外的软件、原始字节数和完整／部分扫描状态。

目录扫描在同一次遍历中生成直属目录、最大文件和文件类型统计，最多保留 20 项大目录／文件及 64 个扩展名桶，超出类型并入“其他”。空间分布明确分开根目录直属文件与未列出的其他目录；点击“深入分析”扫描报告中的子目录，可返回上一层报告。JSON 导出与复制摘要保留统计范围、取消／不完整标记和扫描提示。统计口径是文件逻辑大小，硬链接可能重复计数；不会自动将其他位置的数据归属给软件。每页缓存最近 20 份聚合报告，较早层级的结果可能需要重新分析。

功能设计参考 [BCUninstaller 的筛选与属性呈现](https://github.com/BCUninstaller/Bulk-Crap-Uninstaller/blob/master/doc/BCU_manual.html)、[WinDirStat 的目录与文件类型统计](https://github.com/windirstat/windirstat#major-features)，以及 [UniGetUI 的软件清单导出工作流](https://github.com/Devolutions/UniGetUI#features)，实现沿用本项目已有扫描与页面生命周期，不引入这些软件作为依赖。未提供安装器包 ID 的登记清单不能用于自动重装；缺失登记信息也不能直接判定为残留或不安全软件。

验证：`npm run test:software-ui` 检查清单、导出、逐层分析、取消／休眠、状态恢复与浅深色窗口布局；`npm run test:software-native` 使用隔离应用标识和临时目录检查真实 IPC、根文件与类型聚合。运行前需要 Windows 与 WebView2。

## 设置界面

设置分类会跟随实际滚动位置；鼠标点击平滑定位，滚轮可打断，键盘 Enter 立即定位并聚焦分类标题。小窗口保留带文字的横向分类导航、检查更新与项目入口。

目录迁移、资源策略、清理期限、工具模块和密码剪贴板策略分别显示读取、保存与失败状态。目录读取不会覆盖正在输入的路径；重复提交会被阻止，清理期限会按最新草稿保存，保存失败后保留输入并允许重试。

「开机自动启动」为当前 Windows 用户登记登录启动项。下次登录后 DtKit 直接常驻托盘，不创建主界面或隐藏的桌面空间 WebView；手动再次打开 DtKit 或点击托盘图标会呼出主界面。开关读取真实登记状态，不改动其他启动项；如果 Windows 已在「启动应用」中禁用该项，设置会显示原因，并可取消登记。已有闹钟首次使用此版本时，先正常打开一次主界面，让任务同步为原生后台快照。无主窗口的提醒音交给 Windows 播放；WAV、MP3、M4A 可用，OGG 取决于系统解码器，无法解码时仍保留系统通知。运行 `npm run test:autostart-native` 可在隔离标识与临时便携目录中验证无窗口启动、后台常驻与主窗口恢复。

开关和按钮沿用短过渡；工具模块展开可反向打断，确认弹窗关闭立即处理操作语义，退出动画完成前也能重新打开。键盘操作即时反馈，系统减少动态效果时去掉位移与缩放。运行 `npm run test:settings-ui` 可验证原有流程、并发交互和深浅色布局。

## URL、Cron 与单位工具

- **URL 编码**：区分组件、完整 URL 与表单参数值三种模式；表单模式将空格与字面 `+` 分开处理。支持最多 1,000 行逐行转换，失败时标出行号；查询参数查看保留重复键、空值、原始顺序及 `#` 片段，可复制 JSON 数组。修改输入或模式后需重新转换才能复制结果。
- **Crontab 解释**：支持标准五段时间规则与常用别名，明确显示日期和星期的匹配方式。可选择本地时间或 UTC、起算时间及后续 5/10/20 次；严格晚于起算时刻，最多查找未来 30 年。它预估日历匹配时间，不创建定时任务；不接受 Quartz 扩展、命令正文或 `@reboot`。
- **单位换算**：覆盖数据、长度、质量、温度、面积、速度、体积、压力、能量九类；区分十进制和二进制存储单位、美制液体加仑和热化学卡。支持科学记数法、6/12/15 位有效数字、复制数值及等式；不接受纯空白或十六进制数。精度选项只改变显示，单位互换保留未舍入数值；结果采用 JavaScript 浮点数。

三个工具均支持独立窗口、嵌入页面、深浅色、小窗口与草稿恢复。运行 `npm run test:utility-ui` 可验证实际页面交互。语义参考 [WHATWG URL 标准](https://url.spec.whatwg.org/#application/x-www-form-urlencoded)、[Crontab 手册](https://man7.org/linux/man-pages/man5/crontab.5.html) 与 [NIST 单位换算表](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors)。

## 文件批处理

支持逐次添加文件，或从文件夹导入普通文件，可选择包含子文件夹。每批最多 500 项；目录读取受 2 万条目、3 秒和 32 层遍历预算约束，不跟随符号链接或目录联接，截断和跳过会明确提示。导入只生成待处理清单，离开页面或恢复工作区后丢弃迟到结果。

重命名支持 `{name}` 原名、`{n}` 序号、`{dotext}` 扩展名、`{folder}` 父文件夹名；变量仅展开一次。更多规则依次去除首尾空白、按 Unicode 字符数移除首尾、字面替换、调整原名大小写，扩展名大小写单独设置。改变规则、排序或清单后，必须重新进行原生检查。预览交互参考 [PowerRename](https://learn.microsoft.com/en-us/windows/powertoys/powerrename)，本工具沿用自己的文件操作与恢复逻辑。

可一次移除全部冲突项或当前搜索／冲突筛选匹配的清单项，范围包含尚未展开的分页，不删除磁盘文件。草稿、已检查和任务结果分别标注；CSV 导出完整清单，任务结果保留已完成、等待、未处理及错误提示，删除完毕后仍可导出结果。默认删除移入 DtKit 恢复区，恢复期间本页锁定其他操作；重命名、复制、移动和彻底删除不提供自动回滚。

验证：`npm run test:file-batch-ui` 检查规则、导入、预检失效、批量移除、导出、恢复及浅深色窄窗口；`npm run test:file-batch-native` 仅用隔离应用标识和自动创建的临时文件夹，检查真实导入、重命名、复制／移动、禁止覆盖、取消及删除恢复。

## 桌面整理

在「设置 → 桌面整理」中启用功能，并选择两个并列方式之一：分类侧栏使用右上角热区呼出；桌面空间使用横向玻璃面板，停用原有热区和侧栏。空间平时隐藏，通过独立快捷键或设置中的「打开空间」呼出，在鼠标所在显示器的工作区域居中显示。

首次启用默认注册 `Ctrl+Alt+D`，可在桌面整理或快捷键设置中修改、清除；已有命令面板和工具快捷键保持不变。快捷键逐条恢复，被占用的绑定显示原因并保留配置，其他绑定仍可用；不同窗口同时修改时只更新各自目标。默认快捷键被占用时，空间仍可启用并通过「打开空间」呼出；清除后重启不会自动补回。总开关关闭时，也可点击「启用并打开」。单击文件选中，双击或 `Enter` 用默认应用打开，成功后按设置收起面板，失败则保留面板并显示原因。双击文件夹在空间内进入，`Esc` 依次关闭预览、返回上层文件夹、收起面板。

选中文件后按 `Space` 快速预览：UTF-8 文本上限 512 KB，图片与 PDF 上限 12 MB，其他格式显示文件信息并提供打开入口。PDF 使用本地 PDF.js 渲染，支持翻页、缩放、适合宽度，焦点在页面中也可按 `Esc` 关闭并回到原文件。文件区只有一个 Tab 入口，方向键跨固定区和文件区保持列位置；Tab 离开文件区，Shift+F10 或菜单键可打开文件操作并固定或取消固定。固定项和各区域的拖动顺序保存在本机，重启、刷新或类别筛选不会按最近访问重新排列；子文件夹内的文件也可固定到空间首页。读取、迁移失败或不支持的配置会保留原始数据并停止覆盖写入。旧分类名称和顺序先迁移保存，再移除旧空间布局数据。

面板使用 Windows 实时背景模糊与轻色调玻璃界面，背景合成层、窗口与页面共享按 DPI 缩放的 28px 圆角，关闭系统非客户区绘制，避免浅色标题条与四角矩形残留；呼出时读取少量后方亮度样本，为文字与按钮分区选择明暗，不保存桌面截图；呼出时以 220ms 淡入并轻微放大归位，收起时以 180ms 同步淡出网页内容和原生背景，退场完成后隐藏窗口；快速反向沿当前画面继续，旧关闭计时不会误关新呼出。脚本暂停时仍由原生计时完成收起，减少动态设置与系统动画偏好均生效。分类侧栏以同样的短过渡从顶部滑入、收回，分类内容展开与收起也保留连续过渡。列表变化保留动效，文件名支持两行显示，桌面快捷方式和自定义应用图标优先使用高分辨率真实图标，保留真实图标的颜色与完整外形，不对原图附加圆角裁切；软件、文件和文件夹统一使用圆角玻璃底板、细描边与上沿高光，原图保留约 65% 的底板宽度。无真实图标时保留原创分层矢量图案；设置页实时演示复用同一底板样式。点击“空间设置”文字按钮或卡片右上角的齿轮打开独立设置页，可调整玻璃浓度、高光柔化、图标密度、窗口宽高、打开后收起、失焦收起、减少动态及呼出快捷键。设置页提供可操作的实时演示，拖动时立即反映材质、图标密度和窗口比例，可切换浅色、深色与混合背景，并通过示例文件试用预览、打开后收起和失焦收起。示例不读取或打开真实文件。外观与行为即时同步，实际窗口尺寸下次呼出生效；恢复空间默认设置不更改固定项、排序或快捷键。设置项参考 [Flow Launcher](https://github.com/Flow-Launcher/Flow.Launcher) 和 [Ueli](https://github.com/oliverschwendener/ueli) 的启动器偏好设计，按本项目已有能力实现。空间不改变系统桌面图标的显示状态，用户可通过 Windows 桌面右键菜单自行控制；主界面进入托盘或休眠后仍可通过快捷键呼出。

文件夹显示完整可返回的层级，并提供资源管理器入口；内容超过读取上限时，常驻显示已加载数量、总数和搜索范围。自定义分类与归类记录以单个版本化事务保存，旧配置保留为恢复副本，保存失败不会提交到界面；已有超过新建上限的分类不会在读取时被截断。

玻璃材质与通透感参考 [GlassDesk](https://github.com/everlosttime/glassdesk-open-source)，按 Tauri/Windows 窗口能力独立实现。本项目参考苹果 Liquid Glass 的层次、弧形边缘与输入反馈，实际面板和设置预览复用同一材质。边缘和光晕随指针变化，按下时增强局部光照；减少动态时停止跟随，原生背景模糊不可用时采用较不透明的底面。高光柔化只改变光晕散射，不改变背景模糊半径。当前实现仍使用 Windows 原生背景模糊，未实现真实桌面的透镜折射，不等同于 Apple 系统材质。

验证：`npm run test:desktop-native` 使用隔离的原生测试程序检查真实窗口圆角、原生背景退场、侧栏展开收纳、快速反向、隐藏启动、窗口会话、真实文件预览、模式互斥和快捷键清除后的重启行为，需要 Windows 和 WebView2。`npm run build` 后运行 `python tests/desktop-launcher-ui-smoke.py` 检查打开、预览、固定、拖动排序、动效中断和窗口适配；分类侧栏、应用分类及图标加载回归保留在 `npm run test:ui`。

## 多页面与独立启动

打开工具后点击「新建同类页面」，可同时编辑多个独立页面；也可以新建标签后再选择同一工具。每页的输入、预览、滚动位置独立，切换和前进/后退保留页面，关闭标签释放对应页面。「重命名」可区分不同用途。闹钟任务、已保存白板和便签等实际数据仍共用，修改会读取最新记录以避免覆盖其他页面的操作。

「独立窗口」打开当前种类的一个新工具窗口。「创建启动入口」在桌面创建对应的快捷方式，下次只启动这个工具，不创建主界面，也不启动桌面整理和无关的全局快捷键服务。命令行同样支持：

```powershell
.\DtKit.exe --tool html-preview
```

工具代码和样式按需加载；隐藏的工具页暂停计时器、动画和刷新，HTML 预览会卸载用户脚本沙盒。独立窗口关闭前等待保存完成，然后立即释放窗口；没有窗口或必要后台任务时，单工具进程自动退出。已安排的闹钟、文件作业、局域网分享和敏感剪贴板清理会继续运行。

「主界面休眠」先保存页面草稿，再释放主 WebView，独立工具继续运行；从托盘恢复主界面后还原页面。HTML 编辑器与白板支持草稿恢复。不能安全保存的会话（例如尚未导出的截图或文件选择）、保存失败或超过本机保存上限时，会保留并暂停主 WebView，避免丢失内容。工作区草稿存储在本机，不包含密码输入与文件内容；页面关闭会移除对应的工作区草稿。

## 📖 开发指南

### 工具页面生命周期

`tool-page.html` 为每个页面提供独立的 JS 环境；同一主窗口内的页面复用原生 WebView。工具可在注册信息中提供 `serialize` / `restore` 保存与恢复页面状态，以及异步 `flush` / `destroy` 完成原生草稿写入。实际共享数据应由后端或事务存储管理，不能用历史页面快照覆盖最新数据。

本项目采用**模块化 + 组件化**架构。

### 核心模块

| 模块 | 路径 | 职责 |
|------|------|------|
| 工具注册中心 | `src/tools/toolRegistry.js` | 工具生命周期管理 |
| 应用框架 | `src/main.js` | 标签页、视图切换 |
| 工具模块 | `src/tools/*/index.js` | 独立的工具逻辑 |
| 样式文件 | `src/css/tools/*.css` | 工具独立样式 |

## 区域悬浮

在工具库打开「区域悬浮」，先打开需要关注的应用，再点击「框选悬浮区域」。在同一个窗口内拖动框选，按 Enter 确认，Esc 或右键取消。小窗默认置顶，拖动画面移动、拖动边缘缩放；双击或按 Enter 返回源窗口操作原内容。最多同时打开 6 个小窗，关闭工具页后小窗继续保留，也可通过独立启动入口直接使用。

管理页可找回离屏、隐藏、最小化或开启鼠标穿透的小窗，并调节置顶、纯画面、50% / 100% / 150% 大小与 30%–100% 不透明度。「找回小窗」会解除穿透，恢复拖动与右键操作；「重置显示」恢复标准工具栏与不透明画面。重新框选成功后才替换原小窗，取消会保留原内容，满 6 个时同样可以替换。小窗快捷键：P 置顶、C 纯画面、T 穿透、R 重置、1/2/3 调整为 50%/100%/150%，Esc 关闭。

画面使用 Windows DWM 原生缩略图，无需另装录屏组件。源窗口移动或缩放后，只要原选区仍在窗口内就继续显示；超出范围时暂停，放大源窗口或重新框选即可恢复。选区对应窗口内的固定像素位置，不追踪网页排版、滚动或标签切换。最小化、其他虚拟桌面、受保护视频和应用主动停止后台渲染可能中断画面，声音仍由原应用播放。

交互设计参考 [OnTopReplica](https://github.com/LorenzCK/OnTopReplica)、[PowerToys Crop And Lock](https://github.com/microsoft/PowerToys/blob/main/doc/devdocs/modules/cropandlock.md) 和 [Sumbo](https://github.com/koprodev/Sumbo) 的区域缩略窗、缩放与穿透恢复思路，本功能沿用项目自身的 Rust / DWM 实现。

验证：`npm run test:region-mirror-ui` 检查管理页交互、键盘焦点、异步状态竞态、窄屏与错误提示；`npm run test:region-mirror-native` 在隔离应用标识下创建测试画面，检查真实 DWM 动态像素、裁剪比例、透明穿透、重新框选和窗口生命周期。原生验证需要 Windows 交互桌面、DWM 与 WebView2。

## 📝 桌面便签

在工具库打开「便签」，点击「新建便签」即可在独立小窗中记录内容。支持六种纸张颜色、窗口置顶、拖动缩放、标题与正文搜索；关闭小窗会保存内容，再次打开时恢复位置和尺寸。内容修改后自动保存，`Ctrl+S` 可立即保存。

不需要的便签可先移入回收站，需要时恢复；只有回收站中的便签可以永久删除。为保护尚未保存的编辑，移入回收站前请先关闭对应小窗。便签数据位于应用数据目录的 `Kits/StickyNotes`，随应用数据目录迁移；浏览器预览不写入桌面便签。

便签按需创建窗口，没有定时刷新或启动时批量打开；最多保存 200 张（含回收站），同时打开 8 张。若保存失败，小窗会保留编辑并提供重试；异常退出后的未确认草稿可在再次打开时检查和恢复。

## 🚀 自启动管理

在工具库打开「自启动管理」，可直接检查当前用户与所有用户的常见登录启动程序。默认按所属软件分组，同一软件的注册表与启动文件夹入口放在一起，每条仍保留独立状态和开关；可切换平铺列表。优先按已登记的安装目录识别，同一程序文件也可归组；未确认归属或使用通用系统宿主的项目单独显示。小组尽量完整分页，超大组标记续页。状态卡片可直接筛选；支持名称、启用状态、来源与最近关闭排序，搜索软件名称、启动项名称、命令与路径，清空筛选和导出当前筛选的全部分页。「我关闭的」集中显示由 DtKit 关闭、可以恢复的项目，启停后可撤销上次更改。系统助手中的开机启动入口使用相同功能，也可通过独立启动入口使用。

「添加启动项」选择本地 `.exe` 程序，填写显示名称和可选参数，为当前用户创建启动快捷方式；工作目录设为程序所在目录，同名入口不会被覆盖。新增配置在后续登录时生效。「启动文件夹」可直接打开当前用户的启动目录。CSV 导出保留中文、引号与多行内容，并处理表格公式前缀；关闭时间使用明确的 UTC 格式。

「程序位置」在资源管理器中选中实际程序文件，快捷方式会先读取其目标；「启动文件位置」可定位启动文件或快捷方式。找不到目标时会显示原因，并保留入口详情。工具只读取配置和快捷方式，不会执行检测到的程序。

关闭前保存恢复记录，再停用对应入口；恢复时检查原始命令或文件是否被其他软件改动，遇到冲突不覆盖新配置。软件更新造成注册表旧恢复记录冲突时，可在详情中确认放弃旧记录，再按当前配置管理；保留的启动文件仍存在时不能直接丢弃其恢复记录。任务管理器或 Windows 设置关闭的项目会标明来源，可通过「Windows 启动设置」管理，返回工具后更新一次列表。系统范围的修改可能需要管理员权限。

扫描只在打开工具、手动刷新及操作后执行，没有后台轮询。当前覆盖 Run、RunOnce（一次性登录任务）以及当前用户和所有用户的启动文件夹；计划任务、服务、驱动及其他特殊自动启动方式不在当前列表中。启停影响后续登录启动，不会关闭正在运行的程序。

恢复记录位于应用数据目录 `Kits/SystemAssistant`，按电脑与 Windows 账户隔离，随数据目录迁移时保留原环境记录。旧版没有归属标记的恢复记录可确认来自本机后绑定，也可保留旧文件、为当前电脑建立空记录；两种操作都需勾选确认，且不会切换现有启动配置。恢复文件不可用时仍可查看实际启动配置，并暂停更改以保留原记录。RunOnce 的现有一次性任务仅供查看，避免把临时安装任务当作长期启动项关闭。

本轮交互参考 [Bulk Crap Uninstaller](https://github.com/BCUninstaller/Bulk-Crap-Uninstaller) 的独立管理入口、[Autoruns 官方文档](https://github.com/MicrosoftDocs/sysinternals/blob/main/sysinternals/downloads/autoruns.md)的来源定位与导出方式。实现依据：[Microsoft 登录启动注册表入口](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)、[Windows 启动应用管理](https://support.microsoft.com/en-us/windows/experience/startup-boot/configure-startup-applications-in-windows)。

验证：`npm run test:startup-ui` 检查软件分组与分页、筛选、排序、撤销、导出、添加、恢复记录和“关于”链接；`npm run test:startup-native` 使用隔离应用标识与唯一命名的临时项目验证真实 Windows 启停、原始数据恢复、冲突与快捷方式。不执行测试启动程序，也不修改原有启动项。

## 🖱️ 右键菜单管理

在工具库打开「右键菜单管理」，按文件、文件夹、文件夹空白处、桌面、磁盘和文件类型查看菜单注册项。支持本地搜索、状态与来源筛选；输入 `.pdf` 等扩展名后，可补充扫描该类型的关联菜单。「我关闭的」集中显示可以由 DtKit 恢复的项目。

扫描和修改均按需运行，不加载第三方菜单 DLL、不驻留轮询。普通命令通过隐藏标记关闭；扩展组件按 CLSID 管理，同一组件在多个场景下的菜单会联动，关闭前会显示影响范围。修改前保存恢复记录，重新开启时核对注册表状态后恢复；原始命令和组件注册不会被删除。系统级项目可能需要以管理员身份运行 DtKit。

当前主要覆盖资源管理器的传统菜单，包括 Windows 11「显示更多选项」中的注册项。新版打包应用菜单、程序内部右键菜单和按所选文件动态生成的子菜单不保证完整枚举。系统核心项目、其他软件关闭的项目及不支持安全管理的注册方式会显示只读原因。部分扩展有缓存，修改后可能需要重新打开资源管理器窗口或重新登录；工具不会自动重启资源管理器。

恢复记录位于应用数据目录 `Kits/ContextMenu`，随应用数据目录一起迁移。菜单状态反映注册配置；文件类型、按住 Shift、应用自身设置等条件仍可能影响实际显示。

实现依据：[Microsoft Shell 扩展注册](https://learn.microsoft.com/en-us/windows/win32/shell/reg-shell-exts)、[Windows 11 打包应用菜单](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/integrate-packaged-app-with-file-explorer)。

## 📅 课表

工具库 → 课表。主视图按周显示课程、教室和节次，点击课程编辑，点击空白格添加。支持连续周、指定周、单双周、课程安排复制和同周冲突校验；周数随日期自动推进。

设置分为基本设置、特色设置、导入与导出、其他设置：可调整开学日期、当前周、总周数、周末、非本周课程、每周起始日和逐节作息；支持静态背景图片、学历选择、新学期归档和历史学期切换。课表保存在应用的本地存储中，建议定期导出完整 JSON 备份。

JSON 备份包含课程、设置、背景和最多 10 个历史学期；CSV 可合并或替换课程，导入前有校验和预览；ICS 按本机当地时间导出每次上课，可导入日历；PNG 导出正在查看的一周。

桌面小部件支持今日 / 本周、拖动、缩放和置顶，只在用户添加时创建一个 WebView，不随启动自动打开。数据通过存储事件同步，只在课程开始、结束或跨日时安排一次更新，隐藏或最小化暂停计时，关闭直接释放窗口。

验证：`node --test tests/timetable.test.js`；构建后运行 `python tests/timetable-ui-smoke.py`（脚本自行启动本地静态服务，IPC 使用模拟对象）。

|------|------|
| **可维护性** | 工具逻辑独立，修改一个工具不影响其他工具 |
| **可扩展性** | 添加新工具只需新建一个文件，无需修改框架 |
| **代码复用** | 工具可以共享公共函数和工具类 |
| **性能** | 按需加载工具，不会加载未使用的工具逻辑 |
| **测试** | 每个工具可独立测试 |
| **团队协作** | 不同开发者可以并行开发不同工具 |

## 🔄 工作流程

添加新工具 → 在工具模块中实现 → 注册工具 → 添加 HTML 视图 → 配置框架 → 测试 → 完成

所有流程都有详细文档支持。
