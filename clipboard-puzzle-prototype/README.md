# 剪贴板拼图 · 前端审查原型

这是独立的前端原型，没有注册到 DtKit，也没有修改正式工具。

- `main.html`：完整工具页面。底部深色切换条可比较 A 工作台、B 专注画布、C 素材整理。
- `floating.html`：独立小窗口。建议用约 480 × 700 的窗口查看。

两个 HTML 可直接用浏览器打开，资源均在本目录，不依赖网络或额外前端库。也可以在项目根目录运行：

```powershell
python -m http.server 8768 --bind 127.0.0.1 --directory clipboard-puzzle-prototype
```

然后打开 `http://127.0.0.1:8768/main.html` 和 `http://127.0.0.1:8768/floating.html`。

可以审查：对象拖动和尺寸调整、左键框选、多选一起拖动、剪刀区域截取、插入图形和画笔、按内容显示的右键菜单、背景与吸附辅助线、PNG 导出、任务切换。滚轮平移，Ctrl + 滚轮缩放，空格拖动画布。主页面顶部的“独立窗口”可以打开第二个浏览器小窗口；将对象拖到该窗口会创建副本。

“开始收集”、置顶、过期保留和手动保存展示的是前端状态，不接入系统后台。图片复制受浏览器剪贴板权限约束，可以用下载 PNG 审查输出。数据仅保存在当前页面内存中，刷新或关闭后重置。跨页面复制载荷已用浏览器事件验证，正式实现仍需验证真实 Tauri 独立窗口的拖放。

`review-preview.py` 用于生成实际浏览器截图；结果在 `review-images/`。这些文件属于待审查原型，确认设计后再决定正式实现。
